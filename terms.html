Elara SMS terms (Sole Proprietor)

This program supports private, two-way informational SMS between Elara and the single account holder after explicit consent. It is not marketing or mass outreach.

The account holder opts in only on the public consent page by entering the account-holder number and checking an unchecked-by-default SMS box. The public page shows a labeled carrier-review sample of that same form. Live SMS opt-in uses the form after a private one-use invitation; the server must record the consent receipt before the page confirms live success. Sample submit does not record production consent and does not send SMS. No in-product or SMS-keyword opt-in is offered.

Messages may include replies the account holder requests and occasional Elara-initiated check-ins or reminders only when that capability is supported and enabled. Message frequency varies. Message and data rates may apply. Consent is optional and is not a condition of using Elara.

Reply STOP to opt out. Reply HELP for help. Twilio may handle those protocol keywords for carrier delivery. Reply STOP records a controlling opt-out in Elara’s consent ledger and invalidates send authorization. Reply START does not restore Elara send authorization (Twilio delivery-only). Elara’s outbound gate rejects sends when the latest controlling ledger event is opt-out or there is no consent, even if Twilio would deliver. After STOP, a new private one-use invitation web consent is required before any further outbound. Carriers are not liable for delayed or undelivered messages.
