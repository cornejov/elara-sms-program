Elara SMS consent (opt-in)

Elara is personal technology software operated by a Sole Proprietor. This SMS program is application-to-person: the software sends informational messages to the account holder only (one opted-in user). It is not a marketing list, not a blast campaign, and not person-to-person chat between two consumer phones.

This page is public and does not require a login. Reviewers can verify the full opt-in here. This page does not send SMS.

Who is messaged

  • Recipient: the Elara account holder (the person who owns the software account).
  • No guests, customers, employees, or third-party lists are messaged.
  • Messages are service notifications, replies, and reminders about that user’s Elara software.

Web Form opt-in (path 1)

Workflow: the account holder opens this public URL, reads the disclosures, enters the mobile number that should receive Elara software SMS, checks the SMS consent box (unchecked by default), then submits. Consent is optional and is not required to use Elara software. Messaging consent is separate from any general terms acceptance.

The SMS consent box above loads unchecked. Submit stays blocked until it is checked. Checking it is the affirmative opt-in action.
