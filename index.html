Elara SMS program

Elara is private personal technology operated by a Sole Proprietor. This public site documents its one-user SMS program.

The program is private, two-way informational SMS between the single account holder and Elara. Messages may include replies the account holder requests and occasional Elara-initiated check-ins or reminders only when that capability is supported and enabled. It does not message the public, guests, or a marketing list.

The only opt-in method is the public consent form. Visitors who open that page without a private invitation see a labeled carrier-review sample of the same form (unchecked checkbox, phone field, privacy and terms). That sample does not record live consent and does not send SMS. Live SMS opt-in uses the same form after a private one-use invitation; then the page shows success only after the server has durably recorded the consent receipt.

Contact for this program: open an issue on the public GitHub repository that hosts these pages. Do not use SMS to opt in (no keyword join). Reply STOP records a controlling opt-out in Elara’s consent ledger and invalidates send authorization. Reply START does not restore Elara send authorization (Twilio delivery-only). After STOP, a new private one-use invitation web consent is required before any further outbound.
