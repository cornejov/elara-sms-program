Elara SMS program

Elara is personal technology software operated by a Sole Proprietor in the Technology industry. This public site documents the SMS program that supports that software.

The program sends informational application-to-person text messages from Elara software to the account holder only (service notifications, replies, and reminders). It does not message the public, guests, or a marketing list.

How consent works (reviewers): visit the public consent / opt-in page. The Web Form uses an unchecked-by-default SMS checkbox plus required disclosures. The Other (in-product) path is shown as a public replica on that same page because the software settings screen is private.
